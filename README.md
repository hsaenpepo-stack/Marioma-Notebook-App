# Marioma Notebook

نسخة مصدرية مبنية على هوية **نوت مريومة** كما تم تحديدها في المحادثة.

## الموجود داخل النسخة
- Splash screen
- Main shell with bottom navigation
- Home dashboard with multi-color 3D-style buttons
- Notebook screen with lined paper, watermark identity, search, categories, checklist, formatting toolbar
- Reminder / notification preview screen
- Achievements screen with mother & child identity and baby success section
- Prayer times screen
- Women & Kids resources screen
- Settings / theme preview screen

## طريقة التشغيل
1. ثبت Flutter SDK على جهازك.
2. افتح المشروع في Android Studio أو VS Code.
3. نفذ:
   ```bash
   flutter pub get
   flutter run
   ```
